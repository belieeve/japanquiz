# 日本都道府県クイズ

ウェブブラウザで遊べる日本の47都道府県を学べるインタラクティブな地図クイズゲームです。

## 特徴

- 🗾 47都道府県すべてに対応
- 📱 レスポンシブデザイン（PC・タブレット・スマートフォン対応）
- 🎮 シンプルで直感的な操作
- 📊 正解・不正解のスコア表示
- ✨ スムーズなアニメーション

## 遊び方

1. 画面に「○○県はどこですか？」という問題が表示されます
2. 地図上で正しいと思う都道府県をクリック/タップします
3. 正解なら緑色、不正解なら赤色で結果が表示されます
4. 「次の問題」ボタンで次の問題に進みます

## ローカルで実行

```bash
# リポジトリをクローン
git clone https://github.com/belieeve/japanquiz.git

# ディレクトリに移動
cd japanquiz

# index.htmlをブラウザで開く
open index.html
```
